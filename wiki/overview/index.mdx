**okf is one binary that searches, checks and edits a catalogue of OKF v0.2 bundles, so you can pick the chapter that matches your task: install it, try it, or connect an agent.**

<Aside type="tip" title="Specification first">
okf follows the Open Knowledge Format specification and is adapted when the specification changes. It is bound to OKF v0.2: the v0.2 rules run only in bundles whose root index declares `okf_version: "0.2"`. No release date is promised for a new specification version.
</Aside>

## What okf is

- A single static Go binary named `okf`. It needs no Python and no `uv` at run time. `uv` is needed only by the MCP server that `okf install` registers.
- It works on a *catalogue*: a directory whose subdirectories are OKF *bundles* of Markdown files with YAML frontmatter.
- Four groups of commands, as in `okf --help`: navigation, search, tags and maintenance.
