# PROPERTIES.md

Frontmatter properties.

| Property | Meaning |
|---|---|
| `type` | Registered type (required) |
| `description` | One-line summary |
| `title` | Display title |
| `tags` | Registered tags |
| `status` | draft, stable or deprecated |
| `generated` | Provenance: `by`, `at` |
| `verified` | Review entries: `by`, `at` |
| `stale_after` | Datetime after which the page is stale |
